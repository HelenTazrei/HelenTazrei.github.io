# Helen — Portfolio (نسخه‌ی نهایی)

## فایل‌ها
- `index.html` — صفحه‌ی اصلی
- `bank-statement-mapping.html` — کیس‌استادی ۱
- `services-case-study.html` — کیس‌استادی ۲ (FintraAccount Services)
- `assets/portrait.webp` و `assets/Helen_Tazrei_Resume.pdf` — عکس و رزومه

همه‌ی لینک‌ها نسبی‌اند و هر صفحه یک فایل مستقل است (CSS و JS داخل خودش، بدون وابستگی به ابزار ساخت). فقط فونت‌ها از Google Fonts بارگذاری می‌شوند.

## انتشار
1. کل پوشه را روی همان هاستی که سایت را منتشر کرده‌ای جایگزین کن (Netlify، Cloudflare Pages، GitHub Pages و ...). نام `index.html` باید بماند.
2. اگر دامنه‌ی خودت را وصل کردی، در `<head>` هر صفحه یک `<link rel="canonical">` و تصویر پیش‌نمایش (og:image) اضافه کن.

## نکته
تصاویر داخل صفحه‌ی کیس ۱ (حدود ۱.۶ مگابایت) و کیس ۲ داخل خود HTML ذخیره شده‌اند. بعداً می‌توانی آن‌ها را به فایل جدا در `assets/` ببری تا صفحه‌ها سبک‌تر شوند.
